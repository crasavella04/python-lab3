# Лицензии

Код и содержимое сайта лицензируются раздельно: у программного кода и у текстов разные
сценарии повторного использования, и подходящие для них лицензии тоже разные.

| Что | Лицензия | Файл в репозитории |
|-----|----------|--------------------|
| Тексты отчётов, иллюстрации, результаты экспериментов (`docs/*.md` и изображения) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ru) | `LICENSE-CONTENT` |
| Код: конфигурация сайта, workflow, скрипты, шаблоны (`mkdocs.yml`, `.github/`, `scripts/`, `overrides/`, `docs/javascripts/`) | [MIT](https://opensource.org/license/mit) | `LICENSE` |
| Сторонний код: KaTeX (`docs/assets/katex/`) | MIT, © Khan Academy and other contributors | `docs/assets/katex/LICENSE` |

## Почему так

- **CC BY 4.0** создана для произведений, а не для программ: материалы можно копировать,
  переводить и перерабатывать, в том числе в коммерческих целях, при условии указания авторства.
  Для кода она не подходит: в ней ничего не сказано про исходный текст и патенты.
- **MIT** — короткая разрешительная лицензия для кода: делать с ним можно что угодно, если
  сохранить уведомление об авторском праве. Альтернатива — Apache 2.0: она дополнительно явно
  передаёт права на патенты, но длиннее и требует отмечать изменения в файлах. Для конфигов
  и небольших скриптов её преимущества не нужны, поэтому выбрана MIT.
- Сторонний код сохраняет свою лицензию: файл лицензии KaTeX лежит рядом с ним.

## Как указать авторство при использовании материалов

> «Результаты исследований», crasavella04, https://crasavella04.github.io/python-lab3/,
> лицензия CC BY 4.0. Указать, были ли внесены изменения.
