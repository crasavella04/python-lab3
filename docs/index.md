# Результаты исследований

Сайт с отчётами по заданиям курса РРиИД Python. Он собирается генератором статических сайтов
[Sphinx](https://www.sphinx-doc.org/) с [MyST-Parser](https://myst-parser.readthedocs.io/) и
публикуется автоматически через CI/CD на GitHub Pages и Helios ИТМО.

Для сдачи выбраны два исследовательских задания (T2, T4) и два практических (P3, P4).

## Содержание

- [T2. Конвейер вычислений](t2/index.md): как результаты попадают на страницу и как связать их с кодом и данными.
- [T4. Доставка и безопасность](t4.md): учётные данные способов деплоя, защита CI, сайт без CDN.
- [P3. Данные → результат → сайт](p3.md): расчёт при сборке с кэшем и меткой версии кода и данных.
- [P4. Helios: доставка под контролем](p4.md): релизы, preview веток, healthcheck и откат.
- [О сайте](about.md): как устроены сборка и развёртывание.
- [Отладка](debugging.md): возникшие ошибки и способы их устранения.
- [Лицензии](license.md): CC BY 4.0 на тексты, MIT на код, CC0 на данные.
